# ➗ Simple Calculator App

A lightweight calculator app that performs basic arithmetic operations.

## ✨ Features
- Perform addition, subtraction, multiplication, division  
- Real-time updates with **LiveData**  
- Mathematical evaluations with **Mozilla Rhino engine**  
- Clean and simple user interface  

## 🛠️ Tech Stack
- Kotlin  
- Android Studio  
- LiveData  
- Mozilla Rhino
